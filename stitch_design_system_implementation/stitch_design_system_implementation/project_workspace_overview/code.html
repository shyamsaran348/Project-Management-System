"Current low-income housing models in metropolitan sub-Saharan regions lack integrated renewable energy infrastructures, leading to high utility costs and carbon-intensive living conditions. This project aims to design modular, solar-powered dwelling units that are both economically accessible and carbon-neutral, bridging the gap between urban expansion and energy justice."
